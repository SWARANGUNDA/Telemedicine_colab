# TeleMed AI — Administrator & Operations Guide

This guide covers system monitoring, physician verification, user account management, and security audit logs.

---

## 1. Executive Operations Portal
- Track platform telemetry: Total Patients, Verified Doctors, Today's Assessments, API Latency (12 ms), and System Health (99.98%).

---

## 2. Doctor Credential Verification Queue
- Review submitted physician state licenses, hospital affiliations, identity documents, and malpractice records.
- Action status transitions: **Approve Credentials**, **Reject Application**, or **Request Revision**.

---

## 3. Security Audit Logs
- Export audit trails (CSV/PDF) tracking administrative account activations, credential approvals, and startup diagnostics.
